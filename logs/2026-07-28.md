## Bugs
- **Causa raiz encontrada para o `!` que não funcionava** (notas de 23 e 24/07): não é o motor de
  padrões — `core._scan` **poda o diretório casado antes de descer** (`dirnames[:] = kept`,
  herança do FIX-001), então a negação nunca chega a ser avaliada. Medido:

  | padrões | `meta/legacy/` casa (= poda)? | `GOT.md` ignorado? | `outro.md` ignorado? |
  |---|---|---|---|
  | `meta/legacy/` + `!…/GOT.md` | True | False | True |
  | `meta/legacy/*` + `!…/GOT.md` | False | False | True |

  Ou seja: o motor **já libera** o arquivo; quem o perde é a poda. Contornado por convenção
  (DEC-025); a correção de produto (gerador do editor + `_TREE`) ficou como próxima frente.
- Nenhum bug de código introduzido — não se tocou em `flatdrop/`.

## Aprendizados / armadilhas
- **Poda ≠ filtro.** Ignorar uma pasta e ignorar o conteúdo de uma pasta são coisas diferentes
  quando a varredura poda diretórios: a primeira mata a possibilidade de reincluir. Virou DEC-025
  e entrou no GLOSSARY.
- **Template genérico não é candidato a substituir arquivo vivo refinado.** O atrito se repete a
  cada update do kit; virou seção própria no CEREBRO e crítica no «Feedback para o Kit».
- **Migração de vocabulário é busca-e-troca perigosa:** o que a troca ARRASTA junto (comando,
  caminho, nome de pasta) importa tanto quanto o termo. Registrado no princípio 11 do CEREBRO.
